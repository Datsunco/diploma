# Документация по проекту Task Management App

## Обзор проекта

Task Management App - это веб-приложение для управления задачами полевых команд, которое позволяет создавать, отслеживать и управлять задачами, командами и отчетами. Приложение имеет функционал работы в офлайн-режиме (PWA) и обеспечивает синхронизацию данных при восстановлении соединения.

## Технологический стек

### Frontend
- **React** с **TypeScript** - основной фреймворк для разработки пользовательского интерфейса
- **Redux Toolkit** - для управления состоянием приложения
- **RTK Query** - для работы с API, кэширования данных и оптимизации запросов
- **React Router** - для маршрутизации
- **Shadcn UI** - библиотека компонентов пользовательского интерфейса
- **Tailwind CSS** - для стилизации компонентов
- **Webpack** - для сборки проекта
- **Workbox** - для реализации PWA и офлайн-функциональности

### Backend (планируется)
- **FastAPI** - Python фреймворк для разработки API
- **PostgreSQL** - реляционная база данных
- **SQLAlchemy** - ORM для работы с базой данных
- **JWT** - для аутентификации и авторизации

## Реализованный функционал

### 1. Аутентификация и авторизация

- **Регистрация пользователей** - создание новых учетных записей с валидацией данных
- **Вход в систему** - аутентификация с использованием JWT токенов
- **Обновление токенов** - автоматическое обновление JWT токенов для поддержания сессии
- **Защищенные маршруты** - доступ к страницам только для авторизованных пользователей

### 2. Управление задачами

- **Просмотр списка задач** - с возможностью фильтрации и сортировки
- **Создание новых задач** - с указанием названия, описания, срока выполнения, приоритета и исполнителя
- **Просмотр деталей задачи** - подробная информация о задаче
- **Изменение статуса задачи** - переключение между статусами (todo, in_progress, completed, overdue)
- **Удаление задачи** - с подтверждением

### 3. Управление командами

- **Просмотр списка команд** - с информацией о количестве участников
- **Создание новых команд** - с указанием названия и описания
- **Просмотр деталей команды** - информация о команде и ее участниках
- **Добавление участников в команду** - (интерфейс подготовлен, функционал в разработке)

### 4. Управление отчетами

- **Просмотр списка отчетов** - с возможностью фильтрации
- **Создание новых отчетов** - с указанием названия, описания, даты и прикреплением файлов
- **Экспорт отчетов в CSV** - выгрузка данных для анализа

### 5. Уведомления

- **Просмотр уведомлений** - список всех уведомлений с пометкой о прочтении
- **Отметка уведомлений как прочитанных** - индивидуально или все сразу
- **Удаление уведомлений** - очистка списка уведомлений

### 6. Профиль пользователя

- **Просмотр информации о пользователе** - имя, email, роль
- **Редактирование профиля** - (интерфейс подготовлен, функционал в разработке)
- **Изменение пароля** - (интерфейс подготовлен, функционал в разработке)

### 7. Дашборд

- **Отображение статистики** - количество задач по статусам, активные команды
- **Последние задачи** - список недавно созданных или обновленных задач

### 8. Офлайн-режим

- **Индикатор состояния сети** - отображение статуса подключения
- **Кэширование данных** - сохранение данных для работы без интернета
- **Очередь отложенных действий** - сохранение изменений для синхронизации при восстановлении соединения

## Детали реализации ключевых компонентов

### Redux Store и RTK Query

Redux Toolkit используется для управления глобальным состоянием приложения. RTK Query обеспечивает работу с API, кэширование данных и автоматическую инвалидацию кэша.

#### baseApi.ts
Базовая конфигурация API с настройкой базового URL, обработкой заголовков и механизмом кэширования для офлайн-режима.

#### authApi.ts
API для аутентификации с эндпоинтами для регистрации, входа, получения данных текущего пользователя и обновления токенов.

#### taskApi.ts
API для работы с задачами: получение списка, создание, обновление и удаление задач.

#### teamApi.ts
API для работы с командами: получение списка, создание, обновление команд и управление участниками.

#### reportApi.ts
API для работы с отчетами: получение списка, создание отчетов и экспорт в CSV.

#### notificationApi.ts
API для работы с уведомлениями: получение списка, отметка о прочтении и удаление.

### Слайсы Redux

#### authSlice.ts
Управляет состоянием аутентификации: хранит данные пользователя, токены и статус аутентификации.

#### networkSlice.ts
Управляет состоянием сети: отслеживает статус подключения, хранит отложенные действия для синхронизации.

### Маршрутизация

В `routes/index.tsx` определены все маршруты приложения с защитой для авторизованных пользователей. Используется ленивая загрузка компонентов для оптимизации производительности.

### UI компоненты

Приложение использует компоненты из Shadcn UI, стилизованные с помощью Tailwind CSS. Основные компоненты:

- **Button** - кнопки различных вариантов и размеров
- **Card** - карточки для группировки контента
- **Form** - компоненты для создания форм с валидацией
- **Dialog** - модальные окна для подтверждений и форм
- **Table** - таблицы для отображения данных
- **Select** - выпадающие списки для выбора опций
- **Input** - поля ввода текста
- **Textarea** - многострочные поля ввода
- **Badge** - метки для отображения статусов
- **Alert** - уведомления и предупреждения
- **Toast** - всплывающие уведомления

### Страницы

#### LoginPage и RegisterPage
Страницы для входа и регистрации с валидацией форм и обработкой ошибок.

#### DashboardPage
Главная страница с общей статистикой и списком последних задач.

#### TasksPage, TaskDetailsPage, CreateTaskPage
Страницы для работы с задачами: просмотр списка, деталей задачи и создание новых задач.

#### TeamsPage, TeamDetailsPage, CreateTeamPage
Страницы для работы с командами: просмотр списка, деталей команды и создание новых команд.

#### ReportsPage, CreateReportPage
Страницы для работы с отчетами: просмотр списка и создание новых отчетов.

#### NotificationsPage
Страница для просмотра и управления уведомлениями.

#### ProfilePage
Страница с информацией о пользователе и настройками профиля.
